# Обновление до версии 2

Этот архив содержит исходники бота. Файла `.env`, базы `data/ege.sqlite3`,
журналов и личных данных в нём нет. Не удаляйте существующий каталог бота.

## Если запускаете вручную из /root/ege_bot

1. Остановите старый процесс сочетанием Ctrl+C.
2. Сохраните копию каталога. Например, если такого каталога ещё нет:

```bash
cp -a /root/ege_bot /root/ege_bot_before_v2
```

Если база задана через `DATABASE_PATH` вне папки проекта, после остановки скопируйте
и её каталог отдельно. При работающем боте используйте `backup.py`, а не копирование
одного файла SQLite.

3. Загрузите новый архив на сервер и распакуйте с заменой исходников. Например,
если он сохранён как `/root/ege_bot_v2.zip`:

```bash
unzip -o /root/ege_bot_v2.zip -d /root
cd /root/ege_bot
python3 -m unittest discover -s tests -q
python3 -u bot.py
```

Если файл скачался под другим именем, подставьте его точный путь в команду `unzip`.
В архиве уже есть верхняя папка `ege_bot`: распаковывайте в `/root`, а не внутрь
`/root/ege_bot`, иначе получите лишний вложенный каталог.

4. Откройте `/menu`. Кнопка «Задания ЕГЭ» запускает новую практику.

`.env` сохраняется. Не копируйте `.env.example` поверх `.env` при обновлении.
Обновляются также `ege/telegram.py` и `bot.py`: приоритет IPv4 уже включён,
ручную вставку с заменой `socket.getaddrinfo` повторять не нужно.

## Если используется systemd

Узнайте фактическую папку проекта:

```bash
systemctl cat ege-bot
```

Остановите службу `systemctl stop ege-bot`, сохраните копию проекта и базы,
распакуйте архив во временную папку. Скопируйте содержимое его папки `ege_bot`
в каталог из `WorkingDirectory`, сохранив `.env`, `data` и владельца файлов.
Проверьте тесты из каталога проекта, затем:

```bash
systemctl start ege-bot
journalctl -u ege-bot -n 30 --no-pager
```

Не запускайте одновременно службу и `python3 bot.py`.

## Прогресс и совместимость

- Схема базы не меняется, завершённые попытки и настройки сохраняются.
- Незавершённая задача версии 1 заменяется новой без зачёта и без штрафа.
- Старые ошибки по темам остаются, но повторять будете обновлённые задания.
- Историческая статистика включает старые разминки; это не оценка баллов ЕГЭ.
- Все расчёты локальные. Новых зависимостей, ИИ и платных API нет.

## Быстрая проверка

- Откройте Фано: варианты ответа отсутствуют, ответ нужно ввести.
- В задаче на звук формула решения до подсказок скрыта.
- В логике выражение и таблица присутствуют; ответ — четыре латинские буквы.
- После подсказки задача отмечается «С помощью».
- `getUpdates` при отсутствии сообщений может ждать около 20 секунд — это нормальный long polling.

Вычисления и сценарии проверены локально; доступ к вашему работающему боту
для установки обновления не использовался.
